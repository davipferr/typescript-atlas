# The 80/20 Path

The Pareto rule applied to this atlas: the **20% of features that cover 80% of what a full-stack
developer writes every day**. It is for someone who knows JavaScript but has **zero TypeScript
knowledge**. Read the steps in order. Each one builds on the previous ones, and each link goes
straight to the feature in the atlas.
